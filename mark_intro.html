使用指南

数据准备

为目标学科录入至少2次成绩（触发预警）或3次成绩（触发预测），系统自动完成计算。

预警查看

首页卡片列表中，淡红色背景卡片即为低于平均值的学科，点击可进入详情页查看分析。

预测查看

详情页「下一次成绩预测」栏目显示综合预测结果，图表区可查看均值参考线与趋势对比。

数据导出

支持单学科/综合分析数据的JSON导出，及图表+数据的图片导出，便于存档与分享。

注意事项

  • 预警与预测功能基于本地历史数据计算，数据仅存储在浏览器本地，保障隐私安全。
  • 若需提高预测精度，建议录入至少5次连续成绩，确保峰值数据集与增长趋势的代表性。
  • 导入历史数据后，系统将自动重新计算均值、峰值与预警状态，无需手动刷新。

低于平均值智能预警

功能核心价值

及时发现成绩下滑趋势，避免薄弱学科被忽视，帮助用户针对性补强学习短板。

触发逻辑详解

  1. 用户录入 ≥2 次学科成绩后，系统自动计算历史平均分 avg = (score1 + score2 + ... + scoren) / n
  2. 当最新一次成绩 score_new < avg 时，触发预警
  3. 预警视觉表现：卡片背景变为淡红色，边框加粗为红色，顶部显示「成绩预警」提示文字

交互细节

  • 录入新成绩后，预警状态实时更新，无需手动刷新页面
  • 预警卡片在列表中自动置顶，提升视觉优先级
  • 点击预警卡片可快速查看成绩对比分析

峰值均值回归预测算法升级

算法升级亮点

摒弃传统「整体均值」预测的局限性，聚焦用户「最佳水平区间」，让预测结果更贴合真实潜力。

核心计算步骤

  1. 计算历史成绩整体平均分 avg_total
  2. 筛选出所有 score > avg_total 的成绩，计算峰值均值 avg_peak
  3. 计算最近两次成绩的同比增长率 growth = (score_last - score_prev) / score_prev
  4. 综合预测：predict = avg_peak × 0.6 + (score_last × (1 + growth)) × 0.4
  5. 区间约束：若 predict < 0 则取 0；若 predict > 满分 则取满分

触发条件

需录入 ≥3 次有效成绩，且峰值成绩数量 ≥1，否则不显示预测结果。

数据可视化增强

可视化升级目标

让数据趋势更直观，帮助用户快速识别成绩波动规律与强弱项。

1. 成绩趋势图优化

  • 新增 红色虚线 代表「整体均值」，展示基准水平
  • 新增 绿色细虚线 代表「峰值均值」，展示潜力水平
  • 成绩数据点使用不同颜色区分：高于峰值均值为绿色，介于两者之间为蓝色，低于整体均值为红色

2. 增速图表优化

  • 每次成绩变化量标注正负符号，清晰展示上升/下降趋势
  • 增长率条形图：正增长为绿色，负增长为红色，零增长为灰色
  • 支持鼠标悬停查看具体数值与增长率详情

基础功能迭代

功能迭代重点

保留核心实用功能，优化交互逻辑与视觉层级，提升使用效率。

1. 核心功能保留

  • 成绩录入：支持手动输入分数、考试名称、考试日期，支持批量导入
  • 数据导出：支持 JSON 格式数据导出、图表图片导出（PNG/SVG 格式）
  • 综合分析：学科排名、总分趋势、单科强弱分析
  • 本地存储：数据存储在浏览器 localStorage，无需登录，隐私安全

2. 交互体验优化

  • 卡片排序逻辑：预警卡片置顶 → 预测卡片 → 普通卡片
  • 新增「快速筛选」按钮，可按预警状态、学科类型筛选卡片
  • 优化表单交互，录入成绩后自动计算并刷新分析结果
