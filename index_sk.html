使用说明书

欢迎使用食刻 v3.0！
本说明书将帮助你快速上手这款 AI 智能营养追踪 + 时间轴规划应用。

📱 应用概述

「食刻」是一款基于 AI 技术的个人营养摄入管理应用，创新性地引入「摄入-储备-消耗」三维动态平衡模型，并配备 全天候 AI 时间轴规划功能。通过拍摄食物、记录运动，自动追踪营养摄入与身体有机物储备变化，并由 AI 实时规划剩余时间的饮食和运动计划。

🚀 快速开始

1. 建立健康档案

首次使用填写个人健康信息（基本信息、疾病史、体检数据）。系统将据此计算每日营养目标，并估算体内有机物储备量（糖原、脂肪、蛋白质）。

2. 配置 AI 接口（可选，解锁拍照识别和智能规划）

前往「我的」→「AI 识别接口配置」，填写智谱 GLM API Key（完全免费，注册即得）。配置后可使用：

  • 拍照识别：真实摄像头拍摄食物包装或实物，AI 自动识别营养
  • AI 时间轴规划：每次记录后，AI 自动生成个性化当日饮食/运动计划卡片
API Key 需通过 HTTPS 页面或本地 HTTP 服务（python -m http.server）使用，直接双击 HTML 文件打开会因浏览器 CORS 限制导致 AI 功能不可用。

📸 拍一拍（真实摄像头识别）

拍包装模式

点击取景框调起系统相机或相册，对准食品背面营养成分表拍摄。AI（GLM-4V-Flash）自动识别产品名称、净含量及每100g各营养素含量，进入校对页确认后记录。

拍实物模式

将食物完整放入画面拍摄，AI 识别食物种类、估算重量和每100g营养成分，返回置信度及备选结果，可在校对页手动切换或调整重量。

小提示：图片会自动压缩到最大1200px再识别，既节省流量又加快速度。未配置 API Key 时可从食物数据库手动选择。

⏱️ 今日时间轴（核心新功能）

底部导航第三项「时间轴」，展示完整的 00:00–24:00 全天视图：

左侧 — 实际记录标签

  • 绿色小圆点标记在时间轴左侧，对应每条已记录的饮食或运动
  • 悬停标签展示「时间 + 食物/运动名称」
  • 点击圆点或标签，弹出该次记录的营养/运动详情

右侧 — 计划卡片

卡片跨度与时间刻度对应，卡片从「开始时间」延伸到「结束时间」。三种类型：

  • 🍽️ 大餐（黄色）：正餐计划
  • 🍎 小食（粉色）：加餐/零食计划
  • 🏃 运动（蓝色）：运动计划

卡片格式：

类型 标题
  内容……
  ……
  开始时间–结束时间

AI 自动生成卡片

每次记录饮食或运动后，系统将当前营养摄入量、体内储备、病史、营养目标等信息全部交给 AI，自动规划今日剩余时间的 2-3 个建议卡片（初始为「待定」状态，显示在时间轴上）。

  • 点击顶栏「AI 🤖」按钮，打开 AI 建议侧面板，查看所有待定建议
  • 点击「✓ 采纳」：卡片变为正式计划（蓝底角标消失）
  • 点击「✕ 销毁」：移除该建议
  • 时间重叠时，新的 AI 建议会自动替换旧建议（已采纳的手动卡片不受影响）

手动添加卡片

点击顶栏「＋添加」按钮，选择卡片类型、时间段、标题和内容，即可添加自定义计划卡片。若与现有手动卡片时间重叠，旧卡片会被自动移除。

缩放时间轴

顶栏「−」「+」按钮可缩小/放大时间刻度（40px/格 至 160px/格），方便查看全天概览或聚焦某一时段。

🏃 运动消耗

在首页点击「运动消耗」，选择运动类型并输入时长。系统自动计算总消耗能量（kcal/kJ）及串行有机物分解量（糖原→脂肪→蛋白质），并触发 AI 时间轴重新规划。

消耗优先级（生理顺序）：
① 0-30分钟：主要消耗糖原（肌糖原+肝糖原）
② 30-60分钟：糖原+脂肪混合供能
③ 60分钟以上：脂肪为主，少量蛋白质参与

🏭 身体储备

首页「身体储备」查看糖原、脂肪、蛋白质实时储量；「我的」→「身体储备」还展示维生素/无机盐充足度百分比。摄入食物 → 储备增加；记录运动 → 储备减少。

📊 图表与数据

  • 摄入详情（底部导航）：27项营养素进度条，颜色代表达标率
  • 消耗柱状图：今日各项运动能量/有机物消耗对比
  • 储备趋势图：维生素、无机盐充足度变化

🏥 模拟体检 & 缺乏症风险

「我的」页面可直接点击大色块按钮进入：

  • 模拟体检报告：综合 BMI、血压、血糖、营养达标率、储备水位生成 0-100 健康综合评分
  • 缺乏症风险推算：基于摄入、储备、个人状态，用科学模型估算各类营养素缺乏风险

⚠️ 注意事项

  • 本应用建议不能替代专业医疗诊断，如有疾病请遵医嘱。
  • 身体储备量为估算值，基于标准生理学模型，个体差异可能存在。
  • AI 识别结果存在误差，营养成分表识别后请在校对页仔细核对数值。
  • AI 时间轴规划为参考建议，实际饮食请结合自身感受灵活调整。
  • 所有数据存储在本地浏览器中，清除浏览器数据或重置会导致记录丢失。
  • 建议每3个月或体检后更新健康档案，保持营养目标的准确性。
祝你使用愉快，科学管理每一口、每一步！
